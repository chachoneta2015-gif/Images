Click a tag (image1, video1, audio1…) to insert @tag in the prompt. Tags follow upload order per type; I'm assuming Seedance maps them by that order, so write e.g. “the man from @image1 walks into the room from @image2”. Frame images override references. Video references bill cheaper on Seedance. Local files are sent as base64 data URLs; if a provider rejects them, use a public HTTPS URL.
Load an image here, or press “Doodle / edit” on any generated image.
With a doodle, the model gets the original (“base”) plus a marked copy, and is told to change only the marked region. In the prompt, describe just the change: “replace the red car with two bicycles”. Edits keep the loaded image's aspect ratio, so the aspect ratio setting is off while an image is loaded.
